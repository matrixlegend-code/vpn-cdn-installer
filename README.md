## О проекте

VPN CDN Installer разворачивает серверную конфигурацию, панель управления и CDN origin. Скрипт автоматизирует установку Xray, Nginx/Caddy, сертификатов, firewall, сетевых настроек и клиентских подписок.

Версия 3.0 распространяется через защищённую систему лицензирования. Исходный код установщика и рабочие лицензионные ключи в этом репозитории не публикуются.

## Что нового в v3.0

Версия 3.0 — это не переименование v2, а обновлённая архитектура установки и доставки:

- актуальная установка 3x-ui 3.7.0 и поддержка современной ветки Remnawave;
- отдельные сценарии настройки для VK Cloud, Yandex Cloud, Beeline и Timeweb;
- корректная инструкция Timeweb для origin по IP на порту 80, CNAME и отключения кеширования;
- XHTTP Packet-Up с параметрами маскировки и отдельными профилями провайдеров;
- защищённая доставка: бот выдаёт временную ссылку, а payload передаётся в зашифрованной сессии;
- многоразовая установочная ссылка сроком на 10 часов;
- единый лимит 3 новых сервера за скользящие 24 часа;
- автоматическая проверка Nginx, Xray, CDN-порта и health endpoint после установки;
- улучшенная повторная установка на медленных сетях и увеличенный таймаут загрузки 3x-ui;
- актуальные режимы для новой установки, удалённой ноды и подключения к существующей панели.

## Получение и установка

1. Откройте [@cdnsettingvpn_bot](https://t.me/cdnsettingvpn_bot).
2. Оплатите лицензию или запросите уже купленный ключ командой `/start`.
3. Бот выдаст персональную команду установки.
4. Выполните команду на сервере от имени `root` и следуйте меню установщика.

Команда имеет следующий вид, но содержит персональный токен пользователя:

```bash
curl -fsSL https://cdn.lovisvidos.site/dl/ВАШ_ТОКЕН -o installer \
  && chmod +x installer \
  && ./installer --auth ВАШ_ТОКЕН
```

Не используйте токены из чужих сообщений, видео или скриншотов.

## Лицензирование v3

- установочная ссылка многоразовая в течение 10 часов;
- после истечения срока новую ссылку можно получить через `/start`;
- разрешено до 3 новых серверов за 24 часа;

- payload передаётся серверу в отдельной зашифрованной сессии.

## Чем отличаются CDN

| CDN | Origin | DNS и сертификат | Особенности |
|---|---|---|---|
| **VK Cloud** | HTTP | Домен раздачи и профиль VK | Высокая скорость, поддержка обычной и каскадной схемы |
| **Yandex Cloud** | HTTPS | Домен и TLS origin | Удобен, когда нужен HTTPS до источника |
| **Beeline CDNvideo** | HTTP/HTTPS | Домен, выданный CDNvideo | Используется отдельная ветка конфигурации и параметры провайдера |
| **Timeweb** | IP-адрес сервера, HTTP `:80` | Технический домен `*.cdn.twcstorage.ru` и пользовательский CNAME | Кеширование, Gzip/Brotli и дополнительные переключатели выключаются |

### Настройка Timeweb

В Timeweb создаётся CDN-ресурс с типом источника «IP-адрес». В качестве источника указывается IP сервера на порту 80, HTTPS до origin выключается. После создания ресурса Timeweb выдаёт технический домен вида `xxxx.cdn.twcstorage.ru`, на который направляется пользовательский CNAME в режиме DNS only.

Для туннеля необходимо выключить кеширование и сжатие. Параметр «Игнорировать параметры запроса» также должен быть выключен. Клиентский путь по умолчанию: `/content/media/stream.m3u8`. Конкретные домены и IP установщик показывает после настройки сервера.

### Как выбрать провайдера

- **VK Cloud** — для высокой скорости и уже имеющегося аккаунта VK Cloud.
- **Yandex Cloud** — если требуется HTTPS-соединение до origin.
- **Beeline** — если есть доступ к CDNvideo и нужен его отдельный профиль.
- **Timeweb** — наиболее прямой сценарий с origin по IP и понятной DNS-настройкой.
