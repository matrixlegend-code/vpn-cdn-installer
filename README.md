## О проекте

VPN CDN Installer разворачивает серверную конфигурацию, панель управления и CDN origin. Скрипт автоматизирует установку Xray, Nginx/Caddy, сертификатов, firewall, сетевых настроек и клиентских подписок.

Версия 3.0 распространяется через защищённую систему лицензирования. Исходный код установщика и рабочие лицензионные ключи в этом репозитории не публикуются.

## Возможности

- панели Remnawave и 3x-ui;
- VLESS XHTTP Packet-Up;
- CDN-провайдеры VK Cloud, Yandex Cloud, Beeline и Timeweb;
- установка панели и ноды на одном сервере;
- отдельная панель и удалённая нода;
- подключение CDN к существующей инфраструктуре;
- каскадная схема через relay-сервер;
- автоматическая настройка Nginx/Caddy и TLS;
- генерация подписок для клиентов;
- дополнительные Hysteria2 и gRPC там, где они поддерживаются;
- проверка результата и откат при критической ошибке.

## Требования

| Компонент | Требование |
|---|---|
| Сервер | Ubuntu 22.04 или 24.04, root-доступ |
| Ресурсы | От 1 CPU и 1 GB RAM |
| Домен | Домен с возможностью управления DNS |
| CDN | Аккаунт одного из поддерживаемых провайдеров |
| Каскад | Дополнительный relay-сервер при необходимости |

## Получение и установка

1. Откройте [@cdnsettingvpn_bot](https://t.me/cdnsettingvpn_bot).
2. Оплатите лицензию или запросите уже купленный ключ командой `/start`.
3. Бот выдаст персональную команду установки.
4. Выполните команду на сервере от имени `root` и следуйте меню установщика.

Команда имеет следующий вид, но содержит персональный токен пользователя:

```bash
curl -fsSL https://cdn.lovisvidos.site/dl/ВАШ_ТОКЕН -o installer \
  && chmod +x installer \
  && ./installer --auth ВАШ_ТОКЕН
```

Не используйте токены из чужих сообщений, видео или скриншотов.

## Лицензирование v3

- установочная ссылка многоразовая в течение 10 часов;
- после истечения срока новую ссылку можно получить через `/start`;
- разрешено до 3 новых серверов за 24 часа;
- повторный запуск на уже активированном сервере не занимает новый слот;
- лимит автоматически освобождается по мере истечения 24 часов;
- payload передаётся серверу в отдельной зашифрованной сессии.

## Поддерживаемые CDN

| CDN | Origin | Примечание |
|---|---|---|
| VK Cloud | HTTP | Поддержка XHTTP и каскада |
| Yandex Cloud | HTTPS | Поддержка XHTTP и каскада |
| Beeline CDNvideo | HTTP/HTTPS | Отдельный профиль настройки |
| Timeweb | HTTP, порт 80 | Кеширование и сжатие должны быть выключены |

Для Timeweb установщик выводит пошаговую инструкцию: IP origin, технический домен, CNAME, настройки кеширования и клиентский путь.
