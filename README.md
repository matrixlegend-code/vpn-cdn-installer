## 🛡 Что это?

**VPN CDN Installer** — скрипт на ~5000 строк Python, который **полностью автоматически** разворачивает VPN-сервер, маскируя трафик под обычные запросы к российским CDN.

Трафик идёт через **белые списки провайдеров** — CDN-серверы VK, Yandex, Beeline и Timeweb **не блокируются**, потому что через них работают миллионы обычных сайтов и приложений.

> **Вы просто отвечаете на вопросы — скрипт делает всё сам:**
> Docker, панель, Xray, Nginx, Caddy, сертификаты, firewall, sysctl-тюнинг, генерация подписок.

## 🔄 Каскад (Cascade)

Двойная маскировка трафика — дополнительный уровень защиты:

```
Без каскада:   Клиент → CDN → Exit-сервер → Интернет
С каскадом:    Клиент → CDN → Relay (РФ) → Exit-сервер → Интернет
```

Relay-сервер в России принимает трафик от CDN и перенаправляет на Exit-ноду за рубежом. CDN видит только российский IP, Exit-нода не знает о клиенте.
